# MeCard — Platform Governance Console

Multi-tenant administration and RBAC platform control center for MeCard Platform Owner.

## Capabilities
- **Multi-Tenant Provisioning**: Onboard new client organizations and generate tenant administrator accounts in a single guided flow.
- **Global User Directory**: Full RBAC security controls (`master_admin`, `tenant_admin`, `card_user`, `viewer`).
- **Security Audit Log**: Immutable chronological audit trail recording tenant provisioning, role modifications, and system events.
- **Data Backup & Disaster Recovery**: JSON state export and schema-validated restore.
- **Industrial WEHIRRE Corporate Design**: Collapsible sidebar navigation rail with left-anchored badges and frozen sticky topbar.

## Credentials
- **Master Admin**: `master@mecard.app` / `admin`
- **Master Admin (Alt)**: `admin@mecard.app` / `admin`
